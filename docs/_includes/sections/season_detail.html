It decides which full-width sections have data to show, renders the jump-nav, and composes the self-contained section components (in _includes/sections/season/) in order. State (d.state) is internal: it only gates WHICH sections appear, never any wording — no state is narrated to the reader. Section order below: weekly recaps, standings, trades, draft.
